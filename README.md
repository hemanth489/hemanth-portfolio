## Customize your work
1. Open `index.html` on GitHub and click the pencil icon.
2. Search for `PORTFOLIO SETTINGS` in the file.
3. In the `projects` array, change project titles and descriptions, and add your own URLs in `url:"https://..."`.
4. To use your own project image, upload it to this repository and enter its relative path in `image:"projects/my-work.jpg"`. Create a `projects` folder first if needed.
5. To change your profile picture, upload your photo and name it `pfp.jpg`, replacing the existing file.
6. Click **Commit changes**. GitHub Pages should redeploy automatically.

There are 12 project slots: 4 thumbnails, 4 Reels, 2 long-form edits and 2 Shorts. Sample cards are placeholders, not claims that these are completed client projects.
