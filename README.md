# Hemanth Bhandari — Video Editing Portfolio

A responsive, single-page static portfolio. The website files live in your own GitHub account: https://github.com/hemanth489/hemanth-portfolio

## Customize
- Open index.html and click the pencil (Edit this file).
- Change headings, project descriptions, skills, colors, links and contact email.
- Commit changes to the main branch; the deployed site will update after the Pages workflow finishes.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow under .github/workflows/pages.yml. If Pages is not already enabled, open Settings → Pages and set Build and deployment source to GitHub Actions. Then check Actions for the deployment status.

## Ownership
The repository belongs to your GitHub account. Keep collaborators empty if you want to be the only person who can edit it. A public repository means anyone can view and copy its source; public visibility is required for GitHub Free Pages on a public repository.

## Note
The first project is currently represented by a designed thumbnail card. Upload your MP4 into assets/project-01-podcast-reel.mp4 and add a video element in index.html to embed the actual clip.
